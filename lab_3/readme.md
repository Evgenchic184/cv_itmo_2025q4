БАЗА:
VGG-11 — это сверточная нейронная сеть (CNN) для классификации изображений, известная простой архитектурой из 11 слоев (8 сверточных, 3 полносвязных).  
Исходная VGG-11 была предназначена для классификации 1000 категорий ImageNet.   
Последний полносвязный слой заменили на новый слой с количеством нейронов, равным числу классов в задаче (11).

Описание системы:
Выбрали датасет: https://www.kaggle.com/datasets/trolukovich/food11-image-dataset   
Классификация на 11 классов.  
Дообучили VGG-11
